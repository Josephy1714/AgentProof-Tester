Adversarial evaluation

Safety & robustness

Organize instruction-following, prompt-injection, policy, and tool-use checks.
These are planned evaluation categories, not a certification that an agent is safe.
Instruction followingTest whether the agent follows task constraints and output requirements.
Prompt injectionProbe instruction hierarchy and untrusted-content handling.
Tool-use policyDetect prohibited tools, missing approvals, or invalid tool arguments.
Data handlingTest for disclosure of secrets and sensitive inputs.
Output policyApply explicit deterministic checks and separately label heuristic judgments.
Evidence reviewAttach reproducible cases and human review outcomes to each finding.
